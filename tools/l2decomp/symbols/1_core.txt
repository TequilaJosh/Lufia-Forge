# Bank $80:8000-$80:BFFF: start-up, NMI, maths, menu text, saves, sound driver calls, the event script interpreter
# and the event command handlers. Read from the code and docs/lufia2/*.md (events.md, music.md, graphics.md, settings.md).

# ---- start-up
func 80:8035 Boot                  | Start-up after Reset (and soft reset): FastROM, hardware and RAM set up, the save slots checked, the sound driver uploaded on a cold start (stopped and its samples reloaded when it already runs), the random numbers seeded.
func 80:8084 BootCheckSramAndStart | Waits for the NMI hook to finish, turns soft reset on, checks that the 8 KB SRAM mirrors at $70:2000 (resets otherwise), clears the debug flag; Select+Start held opens screen 6 ($82:E746), then the game starts.
func 80:80D3 ClearLowRam           | Clears WRAM $0002-$1DFF.
func 80:80E1 InitSystemVariables   | Writes the JSL / RTS opcodes of the two NMI hooks ($67, $6C), the screen brightness (forced blank), the joypad repeat mask and other system bytes.
func 80:8117 InitHardware          | Sets the PPU registers from the lists at $80:8212 / $80:825E, clears VRAM, OAM and CGRAM by DMA, fills the OAM buffer and clears WRAM $7E:2000-$3FFF and $7E:8000-$DFFF.
func 80:8281 GoToFieldStart        | Jumps to $83:ACB7 (the game's main sequence after start-up).

# ---- maths and random numbers
func 80:8299 RandomRange           | Random number: A = n gives 0..n-1 (the next random byte times n, high byte). Uses the 55-byte table at $0521.
func 80:82C7 RandomByte            | The next random byte (0-255) from the table at $0521.
func 80:82E7 SeedRandom            | Fills the 55-byte random table at $0521 from the seed in $0558 (subtractive generator, step 21) and stirs it three times.
func 80:832D StirRandomTable       | Mixes the 55-byte random table (each byte XORed with the one 31 / 24 places away); runs when the 55 numbers are used up.
func 80:834C Multiply16x8          | Multiplies the u16 at $4E by the byte at $50; the 24-bit product goes to $51-$53.
func 80:8378 Divide16              | Divides the u16 at $4E by the u16 at $51: quotient in $4E, remainder in A.
func 80:8450 SineByAngle           | A = angle (0-$B3, 2 degrees a step) gives its sine from the table at $80:84BF, sign and size (bit 7 = negative).
func 80:8486 CosineByAngle         | A = angle (0-$B3, 2 degrees a step) gives its cosine from the table at $80:84BF, sign and size (bit 7 = negative).

# ---- NMI and video
func 80:86B5 NmiReturn             | The end of the NMI (read with 16-bit A): reads RDNMI and returns from the interrupt.
func 80:86C1 UpdateScreenFade      | NMI: steps a fade in or out of the screen brightness ($0583) as $0581 asks (bit 7 fading, bit 6 out, low bits speed); clears $0581 when done.
func 80:8703 NmiDmaAndJoypads      | NMI: sends the OAM buffer ($0100) and the palette buffer ($0320) when asked ($72 / $73 bits 6-7), then reads both joypads into $46 (held) and $4A (newly pressed, with auto-repeat).
func 80:87A7 NmiVramUpdates        | NMI (when $71 is set): writes the eight BG scroll registers from $0594, starts the up to four queued DMAs ($75-$78, VRAM or CGRAM address in $79-$80), uploads the BG tilemap buffers and sets HDMAEN from $81.
func 80:87FC UploadBgMaps          | Uploads the tilemap buffers $7E:2000 / $2800 / $3000 to VRAM $0000 / $0400 / $0800 when $74 asks (bits C0, 30, 0C), then clears the requests.
func 80:8285 UploadBgMapsNow       | UploadBgMaps with every register kept (for code that runs with the NMI off).
func 80:882E DmaBgMapToVram        | DMA channel 6: $800 bytes from $7E:X to VRAM address Y.
func 80:884F StartQueuedDma        | Starts one queued DMA: A = channel bits (bit 7 set and 6 clear: a CGRAM address, else VRAM), X = the address.

# ---- save slots (SRAM $70:0000 + slot * $800: +0 state, +1 key, +2 checksum, +4 data)
func 80:9037 CheckSaveSlots        | At start-up: erases every save slot (0-3) whose checksum is wrong; $66 gets a bit for each one erased.
func 80:905F IsSaveSlotEmpty       | A = slot: carry set when the slot is empty (high nibble of its first byte set).
func 80:9099 LoadSaveSlot          | A = slot: decodes it into $7E:3800 and, when it holds a game, loads it ($8E:B993, $85:C60E); carry set when the slot is empty.
func 80:90C9 SaveToSlot            | A = slot: gathers the game into $7E:3800 ($8E:BA0D, $85:C954) and writes it to the slot.
func 80:90E5 IsSaveChecksumBad     | A = slot: carry set when the slot's stored checksum differs from its data.
func 80:90FC SaveChecksum          | A = slot: the sum of the slot's words from +4 (starting at $6502), in $56.
func 80:911C EraseSaveSlot         | A = slot: writes a cleared slot and marks it empty (first byte F0).
func 80:914B DecodeSaveSlot        | A = slot: decodes the slot into $7E:3800 (each byte minus a random number seeded by the slot's key byte).
func 80:9184 EncodeSaveSlot        | A = slot: writes $7E:3800 to the slot with a new random key (each byte plus a random number), the checksum and the state byte.
func 80:91D3 SaveSlotOffset        | A = slot: X = slot * $800 (its offset in SRAM).

# ---- boot screen
func 80:91DF ShowLicenceScreen     | Unpacks file $3F (the Natsume / Taito licence screen) to $7E:4000, sets mode 1, copies its maps and palette to the buffers and starts the NMI hook at $80:92A4.

func 80:99B2 IsSoundDriverRunning  | Carry clear when the APU still waits in its IPL ($BBAA on ports 0-1: a cold start), set when the driver already runs.
func 80:99C7 IsSoundDriverRunningEnd | The end of IsSoundDriverRunning read with 16-bit A.
func 80:99FD SendSoundCommand      | A = driver command, written to APU ports 2 and 3.

func 80:9C0F IplUpload             | Sends the block list at $5D to the APU with the IPL protocol ($BBAA / $CC handshake).

# ---- notes: places where the C# is known to be wrong
note 80:B579 | JSR ($B5BC,X): X = direction * 2 (1 up, 2 down, 3 left, 4 right) picks the handler that adds or takes $63 from $58 / $5A; back here the camera target is set.
note 80:BA42 | JSR ($BA55,X) runs the scene; back here, when $05B5 bit 6 is set the event ends ($099B = 0), else the next command.
