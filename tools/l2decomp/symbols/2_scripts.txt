# Bank $80:C000-$80:FFFF and bank $8E: script helpers, text boxes, map names, the puzzle script
# interpreter (docs/lufia2/scripts3.md), the map loader and map graphics loader.

# ---- event script helpers
func 80:C0D0 ReadEventScriptWord     | Reads a u16 from the running event script (two ReadScriptByte calls, low byte first).
func 80:C0DA SignExtendByte          | Sets the high byte of A to FF when AL is negative, else 00 (A = the signed byte AL).
func 80:C0EC UnreadScriptByte        | Steps the event script pointer Y back one byte, moving into the previous bank ($09B9) when Y leaves $8000.
func 80:C102 SetScriptPointer        | Y = A as a script address: a 16-bit sum that wrapped below $8000 has $8000 added and the script bank ($09B9) moves to the next bank.
func 80:C11C ReleaseAllActors        | Clears bit 01 (held by the event) of $0622 on all 0x28 actor slots.
func 80:C12E FindEventScript         | Looks up a script of the map's event block: AL = id, X = list offset (+2..+C); Y and the script bank are set to its start, carry set (Y = FFFF) when the id is not in the list.
func 80:C195 HoldActorsFrom5         | Sets bit 01 (held by the event) of $0622 on actor slots 5-27.
func 80:C1A7 PlaceActorAtLookup      | Shows actor slot $A7 (clears $0736 and the hidden bit 04 of $0622) and puts it at the tile in $120A/$120B from a map-info lookup.
func 80:C1DF SetSpeakerVoice         | Text voice of the speaker: when $09AB is not FF, finds that actor and sets $1260 = 0x45 + ($1291,X >> 5).
func 80:C01D FindCharacterStart      | Looks up record AL of the map-info list +10 (character starts, 8 bytes): x, y and the rest to $120A.., carry set when there is none.
func 80:C05C FindPoint               | Looks up record AL of the map-info list +0E (points, 3 bytes): x to $120A, y to $120B; carry set (and zeros) when there is none.
func 80:C093 FindMapArea             | Looks up record AL of the map-info list +14 (areas, 5 bytes): its four coordinates to $120A-$120D; carry set when there is none.
