# Bank $85: the battle engine (battle script interpreter, targeting, damage, battle display), plus save packing.
# Names checked against docs/lufia2/battlescript.md and the code; "(guess)" marks inferences.

# ---- battle script interpreter core
func 85:B452 RunBattleScript       | JSL entry of the battle script interpreter: saves registers, clears $0A60, then runs opcodes from [$BB] until 00 or 4F ends the script (called by the runner $81:FAC9).
func 85:B45E NextBattleOp          | Reads the next battle script opcode at [$BB], loads the attacker/target pointers (UpdateCombatantPointers) and jumps through BattleOps; every handler ends here.
func 85:B476 BattleOp4F_Cancel     | Op 4F: ends the script with $0A5B = FF (the action is cancelled). Op 00 (at $85:B473, LDA #0 then a BIT that hides this LDA #$FF) ends it with $0A5B = 0.
func 85:B53D BattleOp01_DoActionNow | Op 01: performs the queued action now (pushes the interpreter state, $81:A832, ApplyActionEffect, pops the state) and goes on with the script.
func 85:B551 BattleOp03_Goto       | Op 03 w: jumps to w, an offset from the owning record ($BB = $0A42 + w). The other jumps come here when taken.
func 85:B560 BattleOp04_IfFailedGoto | Op 04 w: jumps to w when register 10 (the last action failed) is not 0.
func 85:B582 BattleOp05_ChanceGoto | Op 05 b w: jumps to w when a random number 0..FE is below b (chance b/255).
func 85:B598 BattleOp06_IfEqualGoto | Op 06 r v w: jumps to w when register r == value v.
func 85:B5AD BattleOp07_IfNotEqualGoto | Op 07 r v w: jumps to w when register r != value v.
func 85:B5C2 BattleOp08_IfGreaterGoto | Op 08 r v w: jumps to w when register r > value v (signed).
func 85:B5E7 BattleOp09_IfLessGoto | Op 09 r v w: jumps to w when register r < value v (signed).
func 85:B60A BattleOp0A_IfGreaterOrEqualGoto | Op 0A r v w: jumps to w when register r >= value v (signed).
func 85:B62D BattleOp0B_IfLessOrEqualGoto | Op 0B r v w: jumps to w when register r <= value v (signed).
func 85:B652 BattleOp3F_IfCapsuleAttackLearnedGoto | Op 3F b w: jumps to w when bit (b - 1) of the active capsule monster's learned-attack bits (CapsuleLearnedMask) is set.
func 85:B670 BattleOp0C_Set        | Op 0C r v: register r = value v.
func 85:B67C BattleOp0D_Add        | Op 0D r v: register r += value v.
func 85:B698 BattleOp0E_Subtract   | Op 0E r v: register r -= value v.
func 85:B6B7 BattleOp0F_Multiply   | Op 0F r v: register r *= value v (16 x 16 multiply, low 16 bits kept).
func 85:B6D2 BattleOp10_DivideSigned | Op 10 r v: register r /= v, signed: a negative register is negated, divided (24 / 8-bit divide, so only v's low byte counts) and negated back.
func 85:B71D BattleOp55_DivideUnsigned | Op 55 r v: register r /= v unsigned (only v's low byte is the divisor).
func 85:B73B BattleOp11_Random     | Op 11 r: register r = a random number from 0 to register r - 1 (RandomBelow).
func 85:B753 BattleOp12_Ratio      | Op 12 r r2: register r = (register r * 256 / register r2) & FF, a fraction of 256 (LongDivide; never used by the game).
func 85:B77B BattleOp13_GetTargetStat | Op 13 r s: register r = stat s of the targets (register 21); several targets give their average.
func 85:B7A8 BattleOp14_SetTargetStat | Op 14 r s: stat s of every target (register 21) = register r.
func 85:B7CF BattleOp15_GetOwnStat | Op 15 r s: register r = stat s of the script's owner: the attacker (register 20), or the target when $0A52 is set (a defence script).
func 85:B81C BattleOp4E_GetAttackerStat | Op 4E r s: register r = stat s of the attacker (register 20).
func 85:B849 BattleOp16_And        | Op 16 r v: register r &= value v.
func 85:B864 BattleOp17_Or         | Op 17 r v: register r |= value v.
func 85:B87F BattleOp18_Xor        | Op 18 r v: register r ^= value v.
func 85:B89A BattleOp19_Abs        | Op 19 r: register r = abs(register r).
func 85:B8B4 BattleOp1A_Negate     | Op 1A r: register r = -register r.
func 85:B8CC BattleOp1B_Sign       | Op 1B r: register r = sign of register r (-1, 0 or 1).
func 85:B8EB BattleOp1C_GetRoundCounter | Op 1C r: register r = $11E8 (a battle counter, the round number; guess).
func 85:B8F7 BattleOp40_GetCapsuleLearnedMask | Op 40 r: register r = the active capsule monster's learned-attack bits (CapsuleLearnedMask).
func 85:B904 BattleOp1D_ApplyEffect | Op 1D: runs ApplyActionEffect (the effect step of op 01 without performing the action).
func 85:B90B BattleOp1E_ShowAttackName | Op 1E b: register 25 = b, shows enemy attack name b (EnemyAttackName) and sets the message timer $1264 to 120 frames.
func 85:B91F BattleOp1F_SetElement | Op 1F w: register 27 (the attack's element bits) = w.
func 85:B92C BattleOp20_SetCritical | Op 20 b b2: register 28 = b (critical chance), register 29 = b2 (critical multiplier).
func 85:B93D BattleOp21_PhysicalDamage | Op 21 w v b: physical damage: element (reg 27) = w, reg 26 = 20, action kind (reg 23) = 5, damage (reg 2A) = -v, spread (reg 2B) = 20; the last byte is read and ignored.
func 85:B96E BattleOp22_MagicDamage | Op 22 w v b: magic damage: element = w, reg 26 = 1DC, action kind = 0A, damage (reg 2A) = -(v + the attacker's INT + its INT battle bonus), spread = 20; the last byte is read and ignored.
func 85:B9B8 BattleOp23_FixedDamage | Op 23 w: fixed damage: reg 2A = -w, spread = 20, reg 26 = 20. It loads 5 for the action kind but never stores it (a bug in the game: reg 23 keeps its value).
func 85:B9DA BattleOp24_ChangeStatBy | Op 24 t v b: queues a change of stat class t (HP MP maxHP maxMP ATP DFP STR AGL INT GUT MGR, offsets $85:9F04) by v with spread b, in the 6-byte register record of that stat (HP's is reg 2A/2B).
func 85:BA02 BattleOp25_ChangeStatPercent | Op 25 t b: queues a change of stat class t by b percent (record +4) and clears its spread.
func 85:BA28 BattleOp26_SetCureChance | Op 26 e b: chance b of curing status e (status record $85:9F0F + 2).
func 85:BA47 BattleOp27_SetInflictChance | Op 27 e b: chance b of causing status e (status record $85:9F0F).
func 85:BA64 BattleOp28_PlainAttack | Op 28: plain attack: action kind 1, argument 0, no battle animation ($1262 = FF), no name ($1269 = 0).
func 85:BA81 BattleOp29_Defend     | Op 29: defend (action kind 4).
func 85:BA8A BattleOp2A_Flee       | Op 2A: run away (action kind 6); the script goes on.
func 85:BA93 BattleOp2B_UseItem    | Op 2B w: use item w (action kind 3, argument w).
func 85:BAA6 BattleOp2C_CastSpell  | Op 2C b: cast spell b: when the attacker has the MP ($81:F3F4) and its status word (stat 14) lacks bit 1, action kind 12, argument b, loads the spell and shows its name; else action kind 2 and register 10 = 2 (failed).
func 85:BB15 BattleOp2D_CallMonster | Op 2D b: calls monster b to the battle (action kind 7) when AddMonsterToBattle finds room; else register 10 = 2 (failed).
func 85:BB46 BattleOp2E_Action0D   | Op 2E: action kind 0D (never used by the game).
func 85:BB4F BattleOp2F_CountFallenAllies | Op 2F r: register r = how many of the hero side's 5 slots hold a fallen fighter (flag 04 at +0F); 0 when the target is on the enemy side.
func 85:BB7E BattleOp30_GetSideCount | Op 30 r: register r = a count for the attacker's side: $15FE for a monster, else $153C in battle or the party count $0A7A outside (guess: number of fighters).
func 85:BBA2 BattleOp32_ChooseTarget | Op 32 b ...: register 10 = 0, then picks the targets (register 21) with mode b through TargetModes.
table 85:BBB6 TargetModes          | Target modes of op 32: 00 keep, 01 random enemy of the attacker, 02 lowest by a stat, 03 highest by a stat, 04 whole side with fallen heroes, 05 whole target side, 06 self, 07 random own side, 08 random hero.
func 85:BBCA TargetMode00_Keep     | Op 32 mode 00: keeps the current target.
func 85:BBCD TargetMode01_RandomOpponent | Op 32 mode 01: a random living fighter of the side opposite the attacker (random slot 0-5 until one is alive).
func 85:BBF8 TargetMode02_LowestStat | Op 32 mode 02 s n k: ranks the living fighters of the target's side by stat s, lowest first (values negated, shuffled, sorted), and takes k of them from rank n.
func 85:BC26 TargetMode03_HighestStat | Op 32 mode 03 s n k: ranks the living fighters of the target's side by stat s, highest first (shuffled, sorted) and takes k of them from rank n.
func 85:BC39 TargetMode04_SideWithFallen | Op 32 mode 04: the whole target side; on the hero side every hero slot that is filled (fallen ones too) and the capsule monster only while alive (guess: for revival).
func 85:BC56 TargetMode05_WholeSide | Op 32 mode 05: every living fighter on the target's side.
func 85:BC66 TargetMode06_Self     | Op 32 mode 06: the attacker itself (register 21 = register 20).
func 85:BC73 TargetMode07_RandomAlly | Op 32 mode 07: a random living fighter of the attacker's own side.
func 85:BC9C TargetMode08_RandomHero | Op 32 mode 08: a random living hero (capsule monster excluded); register 10 = FF when none is alive.
func 85:BCCF BattleOp35_SetSpecialEffect | Op 35 b: $0A62 = b (the special effect number, e.g. drain).
func 85:BCD8 BattleOp36_SetSpecialEffectIfFailed | Op 36 b: $0A62 = b when register 10 is not 0.
func 85:BCED BattleOp37_WeaponAttack | Op 37: weapon attack: action kind 1; when reg 2A is 0 it becomes -(ATP + register 5E + the ATP battle bonus); spread (reg 2B) = 40.
func 85:BD2C BattleOp3C_AddInt     | Op 3C: adds the attacker's INT to the size of the amount in reg 2A (keeping its sign), as the healing spells do after op 24.
func 85:BD54 BattleOp3D_PlayAnimation | Op 3D b: plays battle animation b now ($81:895E).
func 85:BD5E BattleOp3E_CapsuleAttack | Op 3E b: capsule attack b (action kind 0B, argument b).
func 85:BD6E BattleOp41_DoNothing  | Op 41: action kind 0C, an action that does nothing (a taunt); the script goes on.
func 85:BD77 BattleOp42_CallShared | Op 42 w: calls shared battle script w from the library $96:FADD (saves $BB/$BD in $0A48 and the base in $0A45; one level only).
func 85:BDB2 BattleOp43_Return     | Op 43: returns from a shared script called by op 42.
func 85:BDCB BattleOp44_SetHeroBattleByte | Op 44 i b: battle byte i of the owner's hero (FighterBattleCounters) = b.
func 85:BDDA BattleOp45_GetHeroBattleByte | Op 45 r i: register r = battle byte i of the owner's hero.
func 85:BDF3 BattleOp46_IfHeroBattleByteZeroGoto | Op 46 i w: jumps to w when battle byte i of the owner's hero is 0.
func 85:BE06 BattleOp47_TimedMessage | Op 47 v: message timer $1264 = v, then waits for the message (ShowBattleMessageWait).
func 85:BE13 BattleOp48_CloseMessage | Op 48: closes the battle message ($85:9671).
func 85:BE1A BattleOp49_WaitTimer  | Op 49: waits until the message timer $1264 counts down to 0.
func 85:BE22 BattleOp56_SetMessageTimer | Op 56 v: message timer $1264 = v.
func 85:BE2B BattleOp4A_WaitFrames | Op 4A b: b times: updates the battle display ($85:8A2F) and waits a frame (WaitBattleFrame).
func 85:BE43 BattleOp4B_Effect4    | Op 4B: $81:C35F with A = 4 (a screen effect; guess).
func 85:BE4C BattleOp4C_Effect     | Op 4C b: $81:C35F with A = b (a screen effect; guess).
func 85:BE56 BattleOp4D_DropFallenTargets | Op 4D: keeps only the living fighters in register 21.
func 85:BE68 BattleOp50_MaskTargets | Op 50: when $0A5D bit 7 is clear, register 21 = (register 21 | EF) & $0A5D.
func 85:BE7D BattleOp51_SetReflectFlag2 | Op 51: when reg 26 bit 0 is clear, reg 61 |= 2 (Dark reflector).
func 85:BE96 BattleOp52_SetReflectFlag4 | Op 52: reg 61 |= 4.
func 85:BEBF BattleOp53_Action09   | Op 53 b: action kind 9 with argument b; register 10 = 0.
func 85:BEDA BattleOp54_CastIpStyle | Op 54 b: action kind 19 (a spell cast IP-style, without MP or name) with argument b; register 10 = 0.
func 85:BEF5 BattleOp57_ItemBoost  | Op 57 w b: when the attacker is a hero and his equipped item (+$6E) is w, scales reg 2A (damage) by b/64 and registers 38 and 41 the same way (capped at 100), via ScaleByBoost.
func 85:BF73 ScaleByBoost          | A = A * $09FA / 64, capped at 7FFF (op 57's boost).
func 85:BF97 BattleOp58_EerieLight | Op 58: SaveHeroBattleStats (Eerie light).
func 85:BF9E BattleOp59_SaveMonsterStats | Op 59: SaveMonsterBattleStats.
func 85:BFA5 BattleOp5A_SetAnimation | Op 5A b: battle animation $1262 = b.
func 85:BFAE BattleOp5B_NoLoseOnSelfKill | Op 5B: $7F:F8A5 = 0 (the battle is lost if the monster kills itself).
func 85:BFB6 BattleOp5C_HideDamage | Op 5C: $7F:FAB6 = FF (no damage number shown).

# ---- operand readers and registers
func 85:BFBF ReadScriptByte8       | Reads the next byte of the battle script ([$BB]) into A's low byte.
func 85:BFCA ReadScriptWord        | Reads the next word of the battle script into X.
func 85:BFD8 ReadValueOperand      | Reads a value operand into X: a word with bit 15 set names a register (its low byte), else it is the number itself.
func 85:BFED GetBattleRegister     | X = battle register A: 00-7F the shared words $7F:F40E + 2r, 80-FF the owner's own words at combatant + $15 + 2(r & 7F).
func 85:C023 SetBattleRegister     | Battle register A = X (same layout as GetBattleRegister).
func 85:C05F GetAttackerStat       | X = stat A of the attacker ([$BE]); stats B (IP) and C (level) are bytes.
func 85:C099 StatOffset            | X = the combatant offset of stat A (table $85:9E47: 0 HP, 1 MP, 2 maxHP, 3 maxMP, 4 ATP, 5 DFP, 6 STR, 7 AGL, 8 INT, 9 GUT, A MGR, B IP, C level, D-13 battle bonuses, 14 status).
func 85:C0AA GetHeroBattleByte     | A = battle byte X of the owner's hero (FighterBattleCounters).
func 85:C0B3 SetHeroBattleByte     | Battle byte X of the owner's hero = A.
func 85:C0BE HeroBattleByteIndex   | X = index of battle byte A of the owner's hero: $14E6 + 6 x slot ($97:FE26 maps the fighter bit to a slot); a monster owner crashes (BRK).
func 85:C0F8 FilledSlotMask        | A = bits of the filled slots of side A (bit 7 = enemies): on the hero side every slot with a fighter, fallen too; on the enemy side as LivingSideMask.
func 85:C117 LivingSideMask        | A = bits of the living fighters on side A (bit 7 = enemies; the bit 7 is kept in the result): 5 hero-side slots ($0A64) or 6 monster slots ($0A6E), not fallen (flag 04 at +0F).
func 85:C135 LivingSideMask_EnemyLoop | The enemy-side loop of LivingSideMask (entered with C set from its body).
func 85:C15B LivingSideMask_HeroLoop | The hero-side loop of LivingSideMask (entered with C set from its body).
func 85:C168 CombatantPointer      | X = the combatant struct of fighter A (bit 7 = enemy side, low 6 bits a one-bit mask, or 0 = slot 0): from $0A64 in battle ($0A13 set), else from the party pointers $0A80.
func 85:C1A1 CapsuleLearnedMask    | A = the 3 learned-attack bits of the active capsule monster ($11A3) at its current form ($11A4): word $11CA + 2 x capsule, shifted right 3 x (form - 1).
func 85:C1C7 GetFightersStat       | Stat $FAA8 of every fighter in mask $FAAA, averaged when there are several, into $7F:FAA6 (BRK when the mask is empty).
func 85:C23F SetFightersStat       | Writes $7F:FAA6 into stat $FAA8 of every fighter in mask $FAAA.
func 85:C28F PushScriptState       | Pushes the interpreter state ($BE, $C1, $BB, $0A42, $BD, $0A44) on the stack at $7F:F986 (pointer $0A4B), so op 01 can run other scripts.
func 85:C2C2 PushScriptWord        | Pushes word A on the interpreter state stack.
func 85:C2C3 PushScriptByte        | Pushes byte A on the interpreter state stack.
func 85:C2C9 PopScriptState        | Pops the interpreter state pushed by PushScriptState.
func 85:C300 PopScriptValue        | Reads the next value of the interpreter state stack ($7F:F986 + X).
func 85:C306 BuildTargetRanking    | Reads stat s and fills the ranking list $11EB (3 bytes each: fighter bit, value) with every living fighter on the target's side (used by target modes 02/03).
func 85:C3B2 RankingStatValue      | $7F:FAA6 = the value of ranking stat $09F2 for one fighter: below 80 a plain stat; 80+ a pair from $85:9E71 (e.g. maxHP and HP), their difference when bit 7, as a fraction of the first when bit 6 (HP lost, HP lost %).
func 85:C428 PickFromRanking       | Reads rank n and count k, and ORs the fighter bits of k entries of the ranking from rank n into A (the new targets).
func 85:C45E SortRanking           | Sorts the ranking list by value, highest first (bubble sort, $22 passes: the stat number, a slip for the count that only matters to the unused modes 02-03).
func 85:C49A ShuffleRanking        | Shuffles the ranking list (24 passes of random swaps of neighbours) so ties fall at random.
func 85:C4DE UpdateCombatantPointers | $C1 = the target's combatant struct (register 21), $BE = the attacker's (register 20).

# ---- applying an action's effect to its targets (damage, healing, status, stats, death, rewards)
func 85:CCCE ClearEffectRegisters  | Clears battle registers 22-63 ($7F:F452-$F4D5): the effect of the next action starts from nothing.
func 85:CD10 ReadHeroSpecialEffects | For the 4 hero result records ($7F:F60C, F62A, F648, F666) copies each one's special effect and its value into $0A37-$0A42 (3 bytes each) via ReadResultSpecialEffect.
func 85:CD5D ReadResultSpecialEffect | $09F2 = the special effect of the result record at X (0 when none or when its kind is 5), $09F4 = the word at the record offset $85:A6ED gives for that effect.
func 85:CD8C SaveEffectRegisters   | Copies battle registers 20-63 ($7F:F44E, 0x88 bytes) to the saved copy $7F:F4D6.
func 85:CD9B RestoreEffectRegisters | Copies the saved registers $7F:F4D6 back to registers 20-63.
func 85:CDAA LoadFighterRecordToB5 | Copies the 12-byte battle record of fighter A ($7F, FighterRecordPtr) to [$B5].
func 85:CDD0 LoadFighterRecordToB8 | Clears the effect registers and copies the 12-byte battle record of fighter A to [$B8].
func 85:CDFA FighterRecordPtr      | X = the 12-byte battle record of fighter A in bank $7F (table $85:9EEC: heroes $F55E.., monsters from $F5A6).
func 85:CE21 ApplyActionEffect     | Applies the saved action (registers at $7F:F4D6) to every target and writes the results ($7F:F60C..); when reg 26 bit 1 is set (drain) the attacker then gets back what the targets lost (SumDrainedAmounts).
func 85:CE6F ApplyEffectToAllTargets | For each target bit in the saved reg 21: copies the action registers ([$B5] -> [$B8]), works out rows (RowDefenseFactor), applies it (ApplyEffectToTarget) and writes the result; a reflected action is applied to the attacker instead. When reg 26 bit 8 is set (magic) the amounts are shared: a gain is divided by the number of targets n, a loss scaled by $85:9E9B[n]/256 (2: 147, 3: 128, 4: 114, 5: 104).
func 85:CF68 SumDrainedAmounts     | For a drain: target = the attacker, registers 26-5D cleared, then the HP/MP/stat changes of every successful result record (kind 80) summed and negated into them.
func 85:CFAB AddResultToDrain      | Adds the 11 stat changes of the result record at X (when its kind is 80) to registers 2A, 2D, ... (the drain sum).
func 85:D025 RowDefenseFactor      | Register 22 = the damage cut out of 256: 40 for each of attacker and target in the back row (unless reg 26 bit 6), plus 60 when the target defends (+10 bit 0, unless reg 26 bit 7).
func 85:D080 BackRowFlag           | A = 1 when fighter A stands in the back row: heroes in slots 3 and 4; a monster when some living monster has its front flag $134B set and this one has not.
func 85:D0CD ApplyEffectToTarget   | Applies the action in [$B8] to target reg 21; returns C when it bounces back (reg 26 bit 4 and status bit 7, bit 5 and status bit 6, or reg 61 bit 1). Order: defence (MGR or DFP + battle bonus) and the target's defence script, spread and critical roll, damage formula, status cures and causes, HP, IP gain, MP, stat bonuses, death and rewards.
note 85:D116 | Damage taken: the target may wake up or come to its senses (cure chance of statuses 4 and 5): 100 when hit by its own side, 20 by the other side.
note 85:D1BC | Spreads become random: reg 2B = random(0 .. reg 2B - 1), reg 2E likewise. Critical: random(0..99) < reg 28 multiplies by reg 29 / 16 and ignores the defence; else the multiplier is 10 (x1).
note 85:D20C | Damage = ((|amount| x mult / 16) x (256 + spread) / 256 - defence / 2), not below 0, then / 2, then cut by reg 22 / 256 (rows, defending). Healing = amount x mult / 16 x (256 + spread) / 256.
note 85:D4A5 | HP: healing stops at max HP; damage stops at 0 and 0 HP kills.
note 85:D508 | IP gain when a monster hurts a hero: (1 - cos(90 x damage / HP before)) x 2 x GUT x 128/100, + 12, capped 255, added to the hero's IP (+BC).
note 85:D699 | The target falls: status = dead only, HP 0. A monster adds its EXP to $1605 and gold to $1608 and rolls its item drop (the first drop of the battle is kept in $160B); a hero loses his IP and +BA counts up.
func 85:D711 WouldEffectWork       | Outside battle (items and spells used from the menu): for each target, whether the saved action would change anything (WouldEffectWorkOnTarget); returns C when it would.
